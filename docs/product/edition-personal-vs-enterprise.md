# 个人版 / 企业版 / 管理后台 — 用户说明（产品文案源）

面向最终用户的说明，与界面内 `settings.edition.*` 文案一致。

## 三个入口，别混

| 名称 | 干什么 | 从哪进 |
|------|--------|--------|
| **个人版** | 用自己的/本机身份聊天、做任务 | 标题栏选「个人版」→ 会话工作区 |
| **企业版** | 用公司身份做**同样的**聊天、任务（界面不变） | 标题栏选「企业版」→ 仍是会话工作区 |
| **管理后台** | 管成员、LDAP、飞书、邀请码、邮件 | 侧栏「管理后台」（仅组织管理员） |

**切换「个人版 / 企业版」不会打开管理后台。**

## 个人版 vs 企业版（工作区）

- **界面**：同一套（会话列表、工作区、任务、MCP 等）。
- **差别**：
  - 账号与登录方式（本地 / LDAP / 飞书等）；
  - 数据是否在企业租户下；
  - 标题栏是否显示「个人版 / 企业版」标签与企业名称；
  - **团队**：仅企业版且已加入企业时，侧栏显示「团队（企业版）」；个人版访问 `/team/*` 会提示并回到会话页。
- **未加入企业时**：选「企业版」会引导去登录或填邀请码，不会直接变成管理员页面。

## 管理后台

- 给 **组织管理员** 配置组织，不是日常聊天界面。
- 普通成员日常使用 **企业版工作区** 即可，无需进管理后台。
- 管理员白天聊天仍用企业版工作区；只有「管人、管认证、发邀请码」时才进管理后台。

## 给客服/实施的一句话

> 版本切换只换「个人还是公司身份」，不换界面；管公司要去侧栏「管理后台」，不是切企业版。
